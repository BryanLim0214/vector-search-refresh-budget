Tools and technology

What the project is built with

1 · Data

MS MARCO passages and questions, downloaded from Hugging Face.

2 · Meaning

Sentence-Transformers, run with PyTorch, turns each text into 384 numbers.

3 · Grouping

Faiss groups similar passages into shards and summaries, and finds the true best matches.

4 · Shard search

hnswlib gives each shard its own fast search.

5 · Simulator

Our own Python code with NumPy. pandas and PyArrow store the results.

Code history

Git keeps every change, and the code is public on GitHub. Eight named save points mark the steps of the plan.

Testing

pytest runs 24 automated tests on the simulator and the analysis.

Settings and reruns

Each experiment has one settings file. A script restarts only the runs that did not finish.

Writing

LaTeX with the IEEE template for both papers. matplotlib draws the charts.

Hardware: one Windows 10 computer with Python 3.12. Each simulation process used about 6.5 GB of memory.

About 40 seconds These are the tools behind the simulator, in the order the data moves through them. The passages and questions come from MS MARCO, which we download from Hugging Face. A Sentence-Transformers model, run with PyTorch, turns each passage and question into a list of three hundred eighty-four numbers. Faiss groups similar passages into shards and summaries, and it also finds the true best matches we grade against. A library called hnswlib gives each shard its own fast search. The simulator itself is our own Python code, and the results are stored as tables with pandas and PyArrow. Around the code, Git keeps every change, and the code is public on GitHub, with eight named save points that mark the steps of the plan. pytest runs twenty-four automated tests. Every experiment has its own settings file, and a script restarts only the runs that did not finish. Both papers are written in LaTeX with the IEEE template. Everything ran on one Windows computer, and each simulation process used about six and a half gigabytes of memory.
