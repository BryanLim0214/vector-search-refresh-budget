Nothing here is replayed. Each step, the simulator's own code inserts the new passages, lets each method spend its budget, sends the test questions, and checks the answers against an exact search over every passage. A "new match" is one of a question's 10 true best passages that arrived this step or the step before. When a saved run with the same setting exists, every step is compared with it.
